# 旅印（たびじるし）

**旅先で出会った紙の記憶を、あなたの日本地図に。**

スタンプ、御朱印、入場券・半券など「旅先や街角で受け取る紙の記念品」を写真に撮り、デジタルで保存して日本地図やアルバムでいつでも振り返ることができるWebアプリケーション（PWA対応）です。

---

## 主な機能

1. **旅のアルバム（コレクション一覧）**
   - 新しい順でグリッド表示
   - 種類フィルター（スタンプ／半券・チケット／その他）
   - 写真の拡大表示、編集、安全な削除
   - スマホを傾けると紙が立体的になり光が反射する質感演出（`TiltCard`）
2. **手動トリミング & 自動最適化**
   - 自由比率、1:1、3:4、4:3、16:9 の切り抜き枠をドラッグ操作で調整（`react-image-crop`）
   - 90度回転ボタン
   - ブラウザ側での自動画像圧縮（`browser-image-compression`）によるクラウド容量節約
3. **撮影情報（EXIF）からの自動入力**
   - 写真のEXIF情報（`DateTimeOriginal`）から訪問日を自動判定（`exifr`）
   - GPS情報がある場合は撮影場所を自動入力
   - 位置情報がなければ現在地（Geolocation API）または地図手動ピッカーで指定
4. **日本の白地図 & 47都道府県制覇マップ**
   - 訪問済みの都道府県が美しい深緑に染まるSVG白地図（`d3-geo`）
   - 「スタンプの旅」と「半券・チケットの旅」をタブで切り替え
   - 沖縄県のインセット枠表示
   - 都道府県をタップすると拡大地図が開き、訪れた正確なスポットをピンポイントで描画（スタンプ＝赤、半券＝青）
   - 東京都は23区・多摩の本土を大きく表示し、右上の「諸島を見る」で伊豆・小笠原諸島を切り替え可能
5. **モバイルファースト & PWA対応**
   - スマホのホーム画面に追加してネイティブアプリ感覚で全画面起動可能

- **都道府県境界データ (`src/data/japan-prefectures.json`)**:

## 技術スタック

- **フロントエンド**: React 18, Vite, TypeScript, Tailwind CSS, Lucide React
- **地図・可視化**: d3-geo (白地図), Leaflet / OpenStreetMap (位置指定ピッカー)
- **バックエンド / DB**: Supabase (Postgres, Auth, Storage) ※完全無料枠
- **画像処理**: react-image-crop, browser-image-compression, exifr
- **PWA**: vite-plugin-pwa, Workbox
